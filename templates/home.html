Welcome to the webservice for searching gene families in plants

This application allows you to upload protein sequences, create HMMs (or use Pfam models), perform domain searches, compute alignments, and generate phylogenetic trees – all within a web interface featuring tree and result visualization and report download capabilities.

What can this tool do?

  1. HMM search against plant protein databases
  2. Use a Pfam ID or upload your HMM-File
  3. Sequence alignment via MAFFT
  4. Automatic generation of phylogenetic trees using FastTree
  5. Tree visualization with ASCII
  6. Download results as PDF, CSV, or Newick format
  7. Use Newick file on other visualization websites like tree viewer of ete3

Typical use cases:

  • Homology analysis of proteins from different plant species
  • Detection of functional domains via Pfam profiles
  • Evolutionary comparison of sequence families and their structure

How does it work?

  1. Switch to the Search tab
  2. Upload HMM files or enter a Pfam ID
  3. Select target species
  4. Enable alignment and tree generation
  5. Start the analysis
  6. Visualize and download results
